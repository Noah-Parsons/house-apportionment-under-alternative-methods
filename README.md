# P66 — House apportionment under alternative methods

**Field:** Policy / mathematics  
**Size:** Medium (one project season)  
**Time:** 4-6 weeks

## Question
How would House seats move under Webster, Jefferson, Adams and Hamilton methods with 2020 counts and 2030 projections, and which states gain or lose?

## Why it matters
Apportionment is constitutional, national and rarely explained with current numbers.

## Builds on
your policy writing

## Method
1. Implement the methods; verify against 2020
2. Apply to Census 2030 projections with uncertainty
3. Write a non-partisan explainer with the results

## Deliverable
Explainer + reproducible code.

## Risks
Results are well known for 2020; the projections are the new part.

## Before you start: novelty check
Search Google Scholar / arXiv / GitHub for: _House apportionment methods 2030 projections Webster Huntington-Hill_. If the question is already answered, narrow it or pick another project.

## Possible outlet
Op-ed; SIAM Review (education section)
